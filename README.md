# 🕰 Telegram-бот «Напоминалка»

Бот принимает сообщение вида «через 30 минут позвонить маме» и присылает
напоминание в нужный момент. Работает на чистом Python — без внешних
библиотек, баз данных и серверов. Напоминания хранятся в локальном файле
SQLite, поэтому переживают перезапуск.

## Что умеет

- ⏱ **Разовые напоминания**: «через 10 минут», «завтра в 9:00», «25.12 в 10:00».
- 🔁 **Повторяющиеся**: «каждый день в 8:00», «по будням в 9:30»,
  «каждый понедельник в 19:00».
- 🌍 **Часовые пояса**: по умолчанию Москва, меняется командой `/timezone`.
- 📋 **Список и удаление**: `/list`, кнопки «🗑», `/cancel 2`.
- 😴 **Отложить на 10 минут** прямо из сообщения с напоминанием.
- 💾 **Не теряет данные**: напоминания лежат в `reminders.db`.
- 🧠 **Понимает по-русски**: «напомни мне через полчаса…», «завтра в 9 вечера…»,
  «5 декабря в 12:00…», «в пятницу в 18:00…».

## Быстрый старт (Windows)

1. **Установите Python 3.9 или новее** — [python.org/downloads](https://www.python.org/downloads/).
   При установке обязательно отметьте **«Add python.exe to PATH»**.
2. **Создайте бота в Telegram**:
   - откройте [@BotFather](https://t.me/BotFather);
   - отправьте `/newbot`;
   - придумайте имя и username (username должен заканчиваться на `bot`);
   - скопируйте токен вида `123456789:AAE...`.
3. **Запустите бота**: дважды щёлкните `run.bat`. При первом запуске вставьте
   токен в консоль — он сохранится в `token.txt`, и больше спрашивать не будет.
4. Откройте своего бота в Telegram и отправьте `/start`.

Готово: напишите боту, например, `через 1 минуту проверить` — он ответит
подтверждением и пришлёт напоминание.

### Другие способы запуска

```bat
python bot.py                          :: токен из token.txt
python bot.py --token 123456:AAE...    :: токен аргументом
set BOT_TOKEN=123456:AAE... && python bot.py
```

Токен также можно положить в файл `token.txt` рядом с `bot.py` вручную.

## Примеры фраз

| Сообщение | Когда напомнит |
|---|---|
| `через 30 минут выпить чай` | через 30 минут |
| `через 1 час 30 минут созвон` | через 90 минут |
| `в 18:30 забрать посылку` | сегодня в 18:30 (или завтра, если время прошло) |
| `завтра в 9:00 совещание` | завтра в 09:00 |
| `в пятницу в 18:00 кино` | ближайшая пятница |
| `25.12 в 10:00 купить подарки` | 25 декабря в 10:00 |
| `5 декабря в 12:00 поздравить друга` | 5 декабря в 12:00 |
| `каждый день в 8:00 зарядка` | ежедневно в 08:00 |
| `по будням в 9:30 планёрка` | по будням в 09:30 |
| `каждый понедельник в 19:00 тренировка` | по понедельникам в 19:00 |
| `каждый вечер читать книгу` | ежедневно в 19:00 |

Если дата без года уже прошла, бот перенесёт её на следующий год.
Время без даты, которое уже прошло сегодня, переносится на завтра.
Дату и время можно писать без слова «в»: `завтра 9:00 созвон`.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | приветствие и меню |
| `/help` | подробная справка и примеры |
| `/list` | активные напоминания с кнопками удаления |
| `/remind <текст>` | создать напоминание (то же, что обычное сообщение) |
| `/cancel 2` | удалить напоминание №2 из `/list` |
| `/timezone` | показать и сменить часовой пояс |

## Часовой пояс

По умолчанию — `Europe/Moscow`. Изменить можно так:

- `/timezone Берлин` — по названию города;
- `/timezone Europe/Berlin` — по стандартному идентификатору IANA;
- кнопкой «🌍 Часовой пояс» в меню.

Уже созданные напоминания сохраняют свой пояс: смена пояса влияет на новые.
Если бот работает в другом часовом поясе, поставьте свой — иначе «завтра в 9:00»
будет понято в московском времени.

## Автозапуск

Бот присылает напоминания, **только пока он запущен**. Чтобы не запускать его
вручную:

**Вариант 1 — папка автозагрузки (просто):**

1. Один раз запустите `run.bat` и введите токен (создастся `token.txt`).
2. Нажмите `Win+R`, введите `shell:startup`, Enter.
3. Скопируйте в открывшуюся папку ярлык на `start_background.vbs`.
   Он запускает бота без окна консоли.

**Вариант 2 — Планировщик заданий (надёжнее):**

1. Откройте «Планировщик заданий» → «Создать задачу».
2. Триггер: «При входе в систему».
3. Действие: запустить программу `pythonw.exe` с аргументом `bot.py`
   и рабочей папкой — папкой этого проекта.

Также можно просто держать открытым окно `run.bat` — это нормально.

## Частые проблемы

**«Не найдена база часовых поясов (tzdata)».**
На Windows Python иногда идёт без базы часовых поясов. Выполните
`python -m pip install tzdata` и запустите снова.

**Бот пишет «Конфликт getUpdates».**
Этот же бот уже запущен где-то ещё (второе окно, другой компьютер).
Остановите лишний экземпляр.

**Напоминания не приходят.**
Проверьте, что процесс `python`/`pythonw` запущен и в `bot.log` нет ошибок.
Если компьютер был выключен, пропущенные разовые напоминания придут при
следующем запуске с пометкой о задержке, а повторяющиеся — продолжатся.

**Бот молчит после смены часового пояса.**
Старые напоминания остались в старом поясе — это ожидаемо. Новые создаются
уже в новом.

**Токен попал в чужие руки.**
В [@BotFather](https://t.me/BotFather) выполните `/revoke`, получите новый
токен и замените содержимое `token.txt`.

## Ограничения

- Бот использует long polling: отдельный сервер не нужен, но и компьютер
  должен быть включён.
- «Через месяц» и «через год» считаются приблизительно (30 и 365 дней).
- Напоминания хранятся локально; при переносе проекта скопируйте `reminders.db`.
- Telegram ограничивает длину сообщения 4096 символами; текст напоминания
  ограничен 500 символами.
